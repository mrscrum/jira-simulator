# Backlog Authority

The root `stage-0` through `stage-7` files are the historical v1 backlog and must be preserved; task
history may not be deleted.

The active plan for the approved new implementation is under [`backlog/v2/`](v2/README.md). A fresh
agent must not infer v2 status from the historical root stage labels.

[`docs/v2/implementation-plan.md`](../docs/v2/implementation-plan.md) and the detailed v2 stage
files are optional reference. Active context-sized tasks are created and tracked under
[`backlog/v2/`](v2/README.md) according to [`backlog/v2/README.md`](v2/README.md).
